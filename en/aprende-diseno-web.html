Web Design from Scratch.

Learn step by step how a website works, how to build one with HTML and CSS, and how to publish it so anyone can visit it.

LEVEL Beginner

WHAT YOU WILL LEARN

From a blank page to your first published website.

No previous knowledge is required. We will start by understanding how a website works before writing the first line of code.

Next, you will learn the fundamentals of HTML and CSS, how to adapt a website for mobile devices and how to publish it online.

By the end of this path, you should understand the fundamentals and be able to build a simple website yourself.
