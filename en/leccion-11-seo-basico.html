LESSON 11 · BASIC SEO

Basic SEO before publishing

A well-designed website also makes its content easy for visitors and search engines to understand. This lesson covers the SEO basics to check before publishing.

Level · Beginner Time · 25–35 min Path · Web design

01

What is SEO?

SEO stands for Search Engine Optimization.

It involves improving a website so search engines can understand its content and visitors can find and use the information they need.

Start with clear, useful, well-organised content. Use keywords naturally where they help explain the topic.

02

Write a descriptive title

The title element goes inside each page’s head.

<title>Web design for small businesses | My Studio</title>

Write a title that clearly describes the main topic of the page.

Avoid generic titles like this:

<title>Website</title>
Give each important page its own title based on its content.

03

Add a meta description

A meta description summarises what’s on the page.

<meta name="description"
content="Clear, responsive websites for small businesses, designed and built by My Studio.">

Search engines may use it in search results and may choose a different excerpt from the page.

Write a specific description that helps visitors know what they’ll find.

04

Organise your headings

Headings give content a clear structure.

<h1>Web design for small businesses</h1>

<h2>Services</h2>

<h3>Business website</h3>

<h3>Landing page</h3>

The h1 usually identifies the main topic of the page.

Use h2 for main sections and h3 for subsections within them.

Choose heading levels to reflect the structure. Use CSS to adjust their visual size.

05

Write useful, specific content

Search engines use page content to understand what the page is about.

Write with your readers’ questions and needs in mind.

01

Clearly explain what you offer.

02

Answer questions your visitors actually have.

03

Use descriptive headings.

04

Include relevant terms where they fit naturally.

06

Use simple URLs

File names can become part of a page’s URL.

For example:

example.com/services.html

is clearer than:

example.com/final-new-page-23.html

Use short, descriptive and consistent names.

07

Optimise images

Large image files can slow down page loading.

01

Resize images that are larger than you need.

02

Compress the files.

03

Choose suitable image formats.

04

Use descriptive file names.

For example:

cafe-web-design.jpg

is easier to understand than:

IMG_4827.jpg

08

Use alt text appropriately

As you saw earlier, alt provides a text alternative when an image conveys information.

<img
  src="images/cafe-website.jpg"
  alt="Café website with a menu and a booking form"
>

Describe what the image communicates in its context.

Write alt text for accessibility. Include the information someone needs when they cannot see the image.

09

Connect pages with internal links

Internal links help visitors discover other parts of your site.

<a href="services.html">View web design services</a>

Where possible, use link text that describes the destination.

Clear navigation also helps search engines discover pages on your site.

10

Make sure your website works on mobile

Apply what you learned about responsive design in Lesson 07 before publishing.

Check that:

01

Text is easy to read.

02

Buttons are easy to use.

03

Images fit within the screen.

04

The menu works correctly.

05

The page has no unintended horizontal scrolling.

11

Check for broken links and 404 pages

Test all important links before publishing.

If you write:

<a href="contact.html">Contact</a>

a file with this name must exist at the specified location:

contact.html

A broken link can prevent a visitor from reaching the page they need.

12

SEO is ongoing

Once your site is live, keep reviewing what works for visitors.

Over time, you can improve existing content, add pages, fix technical issues and learn what information visitors find most useful.

A clear structure, useful content and a well-tested site are enough to get started.

SUMMARY

What you’ve learned

  • What SEO stands for.
  • How to write a descriptive page title.
  • What a meta description does.
  • How to organise h1, h2 and h3 headings.
  • Why content should be useful to readers.
  • How to choose clear page names.
  • Why to optimise images.
  • How to use the alt attribute.
  • Why internal links matter.
  • Why to test the mobile layout.
  • Why to check for broken links.
  • How SEO continues after publishing.

PUT IT INTO PRACTICE

Review your project’s SEO

Open all the pages you’ve built during the course.

  1. Review each page’s title.
  2. Add a specific meta description to each page where appropriate.
  3. Check the heading structure.
  4. Review your HTML file names.
  5. Optimise your images.
  6. Check the alt attributes.
  7. Review internal links.
  8. Test the website on mobile.
  9. Check for broken links.
Use keywords naturally. Focus on making the page useful, accessible and easy to navigate.
