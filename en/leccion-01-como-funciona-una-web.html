LESSON 01 · FUNDAMENTALS

How a website works.

Before learning HTML or CSS, you need to understand what happens when you enter an address in your browser and a page appears on your screen.

Level · Beginner Time · 10–15 min Path · Web design

01

What is a web page?

A web page is a digital document that a browser can interpret and display on a screen.

It can contain text, images, buttons, forms, videos, links and many other elements.

When you visit a website, your computer does not receive a single “picture” of the page. It receives files and instructions that the browser uses to build what you see.

02

Three building blocks you should know.

01

HTML

Defines the page structure and content: headings, text, images, buttons and sections.

02

CSS

Controls appearance: colours, sizes, spacing, fonts and layout.

03

JavaScript

Adds behaviour and interaction, such as menus, animations and dynamic actions.

03

What happens when you visit a website?

Imagine typing this into your browser:

digitalukhti.com

In simple terms, this is what happens:

01

You enter the domain in your browser.

02

The browser finds where the website is hosted.

03

The server sends the required files.

04

The browser interprets HTML, CSS and JavaScript.

05

The page appears on your screen.

04

A domain and hosting are not the same.

These two concepts are often confused when someone builds their first website.

DOMAIN

The address.

It is the name someone types to find your website, for example digitalukhti.com.

HOSTING

Where the website lives.

It is the service where the files that make up your website are stored.

An easy way to remember it: the domain is a house address, and hosting is the land on which it is built.

05

What does the browser do?

Chrome, Safari, Firefox and Edge are browsers.

Their job is to read the files of a web page and turn them into an interface you can use.

That is why, when we write HTML and CSS later, we will be giving instructions to the browser.

SUMMARY

What to remember.

  • A website is made up of files.
  • HTML creates the structure.
  • CSS controls appearance.
  • JavaScript adds interaction.
  • The domain is the website address.
  • Hosting stores the files.
  • The browser interprets the files and displays the page.

PUT IT INTO PRACTICE

Look at a website with fresh eyes.

Open a website you regularly use and try to identify:

  1. The domain.
  2. The navigation menu.
  3. The main headings.
  4. The buttons.
  5. The different sections.

You do not need to know how these elements are built yet. The goal is to start recognising the parts that make up a web page.
