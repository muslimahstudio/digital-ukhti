LESSON 12 · FINAL REVIEW

Final website checklist

You’ve reached the final lesson. Before calling your website ready, take time to review its content, functionality, design and setup.

Level · Beginner Time · 20–30 min Path · Web design

01

Review the structure and content

Check that the website explains what the project is about and what visitors can do.

01

The main heading clearly communicates what you offer.

02

Important pages have enough content.

03

The copy has been proofread.

04

Calls to action are clear.

05

Contact information is up to date.

02

Check the navigation

Go through the website as if you were visiting it for the first time.

01

The menu works on every page.

02

It’s easy to return to Home.

03

Links go to the correct destinations.

04

Visitors can navigate from every page.

03

Review the visual design

Consistent design choices give the website a professional look.

01

Colours are used consistently.

02

Fonts are easy to read.

03

Headings follow a clear hierarchy.

04

Spacing between sections is consistent.

05

Similar buttons have similar styles.

04

Check the mobile layout

Review the website on smaller screens before publishing.

01

All content fits within the screen.

02

Headings fit comfortably on small screens.

03

Buttons are easy to tap.

04

Columns rearrange as intended.

05

The mobile menu works correctly.

Try several screen widths, including widths between common phone sizes.

05

Review your images

01

All images load correctly.

02

Image files are appropriately sized and compressed.

03

Images keep their proportions.

04

File names are descriptive.

05

Alt attributes are used appropriately.

06

Test every button and link

Try each interactive element on the website.

01

Menu links.

02

Primary buttons.

03

Internal links.

04

External links.

05

Footer links.

If you see a 404 error, check the file name and the path in href first.

07

Test your forms

If your website has a contact form, test the entire submission process.

Send yourself a test message.

01

Fill in every field.

02

Submit the form.

03

Check that the expected confirmation appears.

04

Verify that you actually receive the message.

08

Do a final SEO review

01

Each page has a descriptive title.

02

Important pages have meta descriptions.

03

Headings follow a logical hierarchy.

04

URLs and file names are clear.

05

Internal links work.

06

Images are optimised.

09

Check your domain and HTTPS

If you use a custom domain, type the address into the browser and check that it works.

https://example.com

Check the address you configured, with or without www.

Use HTTPS when your hosting setup supports it.

10

Test different browsers

When possible, test the website in more than one browser.

For example:

Chrome
Edge
Firefox
Safari

Focus on whether key features work across browsers. Small visual differences are normal.

11

Do a final review as a visitor

Set aside what you already know about the website.

Imagine you’ve just arrived for the first time.

01

Can I quickly tell what this website is about?

02

Can I find the important information?

03

Is it clear what I should do next?

04

Does the website inspire trust?

05

Is anything confusing?

12

Keep improving after launch

Publishing is a milestone, and your website can continue to evolve.

Over time, you can:

01

Update content.

02

Add new pages.

03

Improve SEO.

04

Optimise performance.

05

Improve the experience based on what visitors need.

A clear first version that works gives you a foundation to build on.

FINAL CHECKLIST

Before calling your website ready

  • Content reviewed.
  • Navigation checked.
  • Design consistent.
  • Mobile layout reviewed.
  • Images optimised.
  • Buttons and links working.
  • Forms tested.
  • Basic SEO reviewed.
  • Domain checked.
  • HTTPS active where applicable.
  • Tested at different screen sizes and in different browsers.
  • Final review from a visitor’s perspective.

FINAL PROJECT

Review and complete your first website

Use this checklist to review the project you’ve built throughout the 12 lessons.

Test each part of the website in use.

  1. Visit every page.
  2. Test every link.
  3. Check the mobile and desktop layouts.
  4. Proofread the copy.
  5. Check the images.
  6. Test the forms.
  7. Review the SEO basics.
  8. Check the domain and HTTPS if you use them.
