Création web à partir de zéro.

Apprenez pas à pas comment fonctionne un site web, comment le créer avec HTML et CSS et comment le publier pour que chacun puisse le consulter.

CE QUE VOUS APPRENDREZ

D’une page blanche à votre premier site publié.

Aucune connaissance préalable n’est nécessaire. Nous commencerons par comprendre comment fonctionne une page web avant d’écrire la première ligne de code.

Vous apprendrez ensuite les bases du HTML et du CSS, comment adapter un site aux appareils mobiles et comment le publier sur Internet.

L’objectif est de comprendre les bases à la fin du parcours et de pouvoir construire vous-même une page web simple.
