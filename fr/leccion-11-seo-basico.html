LEÇON 11 · BASES DU SEO

Les bases du SEO avant la publication.

Un site ne doit pas seulement être beau. Il doit aussi aider les moteurs de recherche et les visiteurs à comprendre son contenu. Cette leçon présente les bases du SEO à vérifier avant la publication.

Niveau · Débutant Durée · 25–35 min Parcours · Création web

01

Qu’est-ce que le SEO ?

SEO signifie Search Engine Optimization, soit optimisation pour les moteurs de recherche.

Cela consiste à améliorer différents aspects d’un site pour aider les moteurs de recherche à comprendre son contenu et offrir une bonne expérience aux visiteurs.

Le SEO ne consiste pas à répéter de nombreuses fois des mots-clés. Il commence par un contenu utile, clair et bien organisé.

02

Écrivez un bon title.

Dans le `head` de chaque page, nous trouvons la balise title.

<title>Création web pour petites entreprises | Mon Studio</title>

Le titre doit décrire clairement le contenu principal de la page.

Évitez les titres génériques comme :

<title>Page web</title>
Chaque page importante doit avoir son propre titre, lié à son contenu.

03

Ajoutez une meta description.

La meta description fournit une courte description du contenu de la page.

<meta name="description"
content="Conception et développement de sites clairs, responsive et professionnels pour les petites entreprises.">

Les moteurs de recherche peuvent utiliser cette information pour présenter une page dans leurs résultats, même s’ils n’affichent pas toujours exactement le texte que vous avez écrit.

Essayez de rendre la description précise et utile pour comprendre ce que trouvera le visiteur.

04

Utilisez une structure de titres logique.

Les titres aident à organiser le contenu.

<h1>Création web pour petites entreprises</h1>

<h2>Services</h2>

<h3>Site vitrine d’entreprise</h3>

<h3>Landing page</h3>

Le `h1` représente généralement le titre principal du contenu de la page.

Les `h2` organisent les grandes sections et les `h3` peuvent servir aux sous-sections.

Choisissez les titres selon la structure du contenu et pas uniquement selon leur taille visuelle.

05

Créez un contenu utile et précis.

Les moteurs de recherche ont besoin de contenu pour comprendre le sujet d’une page.

Mais ce contenu doit être écrit avant tout pour les personnes.

01

Expliquez clairement votre offre.

02

Répondez aux véritables questions de vos visiteurs.

03

Utilisez des titres descriptifs.

04

Évitez le contenu créé uniquement pour répéter des mots-clés.

06

Utilisez des URL simples.

Les noms de fichiers font aussi partie de l’adresse d’une page.

Par exemple :

miproyecto.com/servicios.html

est plus clair qu’une adresse comme :

miproyecto.com/pagina-final-23-nueva.html

Utilisez des noms courts, descriptifs et cohérents.

07

Optimisez les images.

Des images trop lourdes peuvent ralentir le chargement d’une page.

01

Réduisez les dimensions si elles sont inutilement grandes.

02

Compressez les fichiers.

03

Utilisez des formats adaptés.

04

Donnez des noms descriptifs aux fichiers.

Par exemple :

diseno-web-cafeteria.jpg

est plus compréhensible que :

IMG_4827.jpg

08

Utilisez correctement l’attribut alt.

Comme nous l’avons vu, `alt` fournit une alternative textuelle lorsqu’une image transmet une information.

<img
  src="images/web-cafeteria.jpg"
  alt="Site web d’un café avec menu et système de réservation"
>

Décrivez l’image selon sa fonction et son contexte.

Ne remplissez pas l’attribut alt de mots-clés. Son objectif principal est l’accessibilité et la transmission des informations pertinentes de l’image.

09

Reliez vos pages avec des liens internes.

Les liens internes aident les visiteurs à découvrir d’autres parties du site.

<a href="servicios.html">Voir les services de création web</a>

Utilisez si possible des textes de lien qui expliquent la destination.

Une navigation claire aide aussi les moteurs de recherche à découvrir les pages du site.

10

Votre site doit fonctionner sur mobile.

Le design responsive appris dans la leçon 07 est aussi important avant la publication.

Vérifiez :

01

Que le texte est facile à lire.

02

Que les boutons sont faciles à utiliser.

03

Que les images ne débordent pas de l’écran.

04

Que le menu fonctionne correctement.

05

Qu’il n’y a pas de défilement horizontal accidentel.

11

Évitez les liens cassés et les pages 404.

Avant de publier, testez tous les liens importants.

Si vous écrivez :

<a href="contacto.html">Contact</a>

il doit réellement exister un fichier nommé :

contacto.html

Un lien cassé nuit à l’expérience du visiteur et à la qualité générale du site.

12

Le SEO est un processus continu.

Publier un site ne signifie pas que le travail SEO est terminé.

Avec le temps, vous pouvez améliorer les contenus, ajouter des pages, corriger les problèmes techniques et étudier les informations les plus utiles pour vos visiteurs.

Vous n’avez pas besoin de maîtriser le SEO pour publier votre premier site. Commencez par une structure solide, un contenu utile et une page techniquement soignée.

RÉSUMÉ

Ce que vous avez appris.

  • Ce que signifie SEO.
  • Comment écrire un title descriptif.
  • Le rôle de la meta description.
  • Comment organiser h1, h2 et h3.
  • Pourquoi le contenu doit être utile aux personnes.
  • Comment utiliser des noms de pages clairs.
  • Pourquoi optimiser les images.
  • Comment utiliser correctement l’attribut alt.
  • L’importance des liens internes.
  • Pourquoi vérifier la version mobile.
  • Pourquoi éviter les liens cassés.
  • Pourquoi le SEO continue après la publication.

MISE EN PRATIQUE

Effectuez une vérification SEO de votre projet.

Ouvrez toutes les pages du site créé durant ce parcours.

  1. Vérifiez le title de chaque page.
  2. Ajoutez une meta description différente lorsque cela convient.
  3. Vérifiez la structure des titres.
  4. Vérifiez les noms de vos fichiers HTML.
  5. Optimisez les images.
  6. Vérifiez les attributs alt.
  7. Vérifiez les liens internes.
  8. Testez le site sur mobile.
  9. Vérifiez qu’il n’y a pas de liens cassés.
N’essayez pas d’introduire des mots-clés artificiellement. Une page claire, utile, accessible et bien structurée constitue une bien meilleure base.
