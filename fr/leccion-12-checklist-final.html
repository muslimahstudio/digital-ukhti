LEÇON 12 · VÉRIFICATION FINALE

Checklist finale de votre site.

Vous avez atteint la fin du parcours. Avant de considérer un site comme terminé, il faut vérifier soigneusement son contenu, son fonctionnement, son design et sa configuration.

Niveau · Débutant Durée · 20–30 min Parcours · Création web

01

Vérifiez la structure et le contenu.

Commencez par vérifier que le site explique clairement le projet et ce que peut faire le visiteur.

01

Le titre principal présente clairement la proposition.

02

Les pages importantes ont suffisamment de contenu.

03

Les textes sont relus et sans erreurs évidentes.

04

Les appels à l’action sont clairs.

05

Les coordonnées sont à jour.

02

Vérifiez la navigation.

Parcourez le site comme si vous le découvriez pour la première fois.

01

Le menu fonctionne sur toutes les pages.

02

Il est facile de revenir à l’Accueil.

03

Les liens mènent au bon endroit.

04

Aucune page n’est isolée sans navigation.

03

Vérifiez le design visuel.

Un site n’a pas besoin de nombreux effets pour paraître professionnel. Il a besoin de cohérence.

01

Les couleurs sont utilisées de manière cohérente.

02

Les polices sont lisibles.

03

Les titres ont une hiérarchie claire.

04

Les espacements entre les sections sont cohérents.

05

Les boutons similaires utilisent des styles similaires.

04

Vérifiez la version mobile.

Ne publiez pas un site après avoir vérifié uniquement sa version sur ordinateur.

01

Aucun contenu ne déborde de l’écran.

02

Les titres ne sont pas trop grands.

03

Les boutons sont faciles à toucher.

04

Les colonnes se réorganisent correctement.

05

Le menu mobile fonctionne correctement.

Testez différentes largeurs d’écran, pas uniquement un seul modèle de téléphone.

05

Vérifiez les images.

01

Toutes les images se chargent correctement.

02

Aucun fichier n’est inutilement lourd.

03

Les images conservent leurs proportions.

04

Les noms de fichiers sont clairs.

05

Les attributs alt sont correctement utilisés.

06

Testez tous les boutons et les liens.

Cliquez sur chaque élément interactif du site.

01

Liens du menu.

02

Boutons principaux.

03

Liens internes.

04

Liens externes.

05

Liens du footer.

Si une erreur 404 apparaît, vérifiez d’abord le nom du fichier et le chemin écrit dans href.

07

Testez les formulaires.

Si votre site possède un formulaire de contact, vérifier son apparence ne suffit pas.

Envoyez vous-même un message de test.

01

Remplissez tous les champs.

02

Envoyez le formulaire.

03

Vérifiez que la confirmation attendue apparaît.

04

Vérifiez que le message arrive réellement.

08

Effectuez une dernière vérification SEO.

01

Chaque page possède un title adapté.

02

Les pages importantes ont une meta description.

03

Les titres ont une hiérarchie logique.

04

Les URL et les noms de fichiers sont clairs.

05

Les liens internes fonctionnent.

06

Les images sont optimisées.

09

Vérifiez le domaine et HTTPS.

Si vous utilisez votre propre domaine, saisissez directement l’adresse dans le navigateur et vérifiez qu’elle fonctionne.

https://miproyecto.com

Vérifiez aussi la version configurée avec ou sans `www`.

La connexion doit utiliser HTTPS lorsque votre configuration le permet.

10

Testez différents navigateurs.

Lorsque c’est possible, testez la page dans plusieurs navigateurs.

Par exemple :

Chrome
Edge
Firefox
Safari

Vous n’avez pas besoin de chercher une présentation absolument identique partout, mais les fonctions principales doivent fonctionner correctement.

11

Effectuez une dernière vérification comme visiteur.

Oubliez un instant que vous avez créé la page.

Imaginez que vous arrivez pour la première fois.

01

Est-ce que je comprends rapidement le sujet du site ?

02

Est-ce que je sais où trouver les informations importantes ?

03

Est-ce que je sais quelle action effectuer ensuite ?

04

La page inspire-t-elle confiance ?

05

Y a-t-il quelque chose que je trouve confus ?

12

Un site n’est jamais complètement terminé.

La publication est une étape importante, mais une page peut continuer à évoluer ensuite.

Avec le temps, vous pourrez :

01

Mettre à jour les contenus.

02

Ajouter de nouvelles pages.

03

Améliorer le SEO.

04

Optimiser les performances.

05

Améliorer l’expérience selon les besoins réels.

La première version n’a pas besoin d’être parfaite. Elle doit fonctionner, être claire et vous donner une base pour continuer à progresser.

CHECKLIST FINALE

Avant de considérer votre site comme prêt.

  • Contenu relu.
  • Navigation vérifiée.
  • Design cohérent.
  • Version mobile vérifiée.
  • Images optimisées.
  • Boutons et liens fonctionnels.
  • Formulaires testés.
  • Bases du SEO vérifiées.
  • Domaine vérifié.
  • HTTPS actif lorsque cela s’applique.
  • Tests à différentes tailles et dans différents navigateurs.
  • Dernière vérification comme visiteur.

PROJET FINAL

Vérifiez et terminez votre premier site.

Utilisez cette checklist pour vérifier le projet construit durant les 12 leçons.

Ne poursuivez pas simplement parce que la page « est jolie ». Testez réellement chaque élément.

  1. Parcourez toutes les pages.
  2. Testez tous les liens.
  3. Vérifiez le mobile et l’ordinateur.
  4. Relisez les textes.
  5. Vérifiez les images.
  6. Testez les formulaires.
  7. Effectuez la vérification SEO.
  8. Vérifiez le domaine et HTTPS si vous les utilisez.

PARCOURS TERMINÉ

Vous avez terminé Création web à partir de zéro.

Vous avez commencé par comprendre ce qui se passe lorsqu’on consulte un site et terminé en construisant, mettant en forme et vérifiant votre propre projet.

Vous connaissez maintenant les bases du HTML, du CSS, du design responsive, de la navigation, des images, des sites multipages, des domaines et du SEO.

Vous pouvez continuer à vous entraîner et construire des projets de plus en plus complets.
