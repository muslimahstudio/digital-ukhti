LEÇON 08 · CONTENU

Ajoutez des images, des boutons et des liens.

Un site a besoin de plus que des titres et des paragraphes. Dans cette leçon, vous apprendrez à ajouter des images, créer différents types de liens et concevoir des appels à l’action qui facilitent la navigation.

Niveau · Débutant Durée · 25–30 min Parcours · Création web

01

Ajoutez une image avec HTML.

Les images sont ajoutées avec la balise img.

<img src="../imagen.jpg" alt="Description de l’image">

Contrairement à de nombreuses autres balises HTML, img n’a pas besoin de balise fermante.

Nous trouvons ici deux attributs importants :

01

src indique l’emplacement du fichier image.

02

alt fournit une alternative textuelle adaptée lorsque l’image transmet une information.

02

Organisez vos images.

Lorsqu’un site se développe, il est utile d’organiser les fichiers dans des dossiers.

Nous pouvons créer un dossier nommé :

images

La structure du projet pourrait être la suivante :

mi-primera-web/
├── index.html
├── styles.css
└── images/
    └── escritorio.jpg

Depuis `index.html`, l’image serait alors chargée avec :

<img src="images/escritorio.jpg" alt="Bureau de travail">
Les chemins doivent correspondre exactement au nom et à l’emplacement des fichiers.

03

L’attribut alt.

L’attribut alt ne doit pas être utilisé comme une liste de mots-clés.

Sa fonction principale est de fournir une alternative textuelle lorsqu’une image apporte une information et ne peut pas être perçue visuellement.

Par exemple :

<img
  src="images/proyecto-web.jpg"
  alt="Page d’accueil d’un studio de création web"
>

Si une image est purement décorative et n’apporte aucune information, vous pouvez utiliser un alt vide :

<img src="images/decoracion.jpg" alt="">

04

Rendez les images responsive.

Nous avons vu cette règle dans la leçon précédente :

img {
  max-width: 100%;
  height: auto;
}

Elle évite qu’une image soit plus large que l’espace disponible.

Nous pouvons aussi contrôler la façon dont elle occupe un conteneur :

.project-image {
  width: 100%;
  height: 400px;
  object-fit: cover;
}

object-fit: cover permet de remplir l’espace en conservant les proportions, même si une partie de l’image est recadrée.

05

Créez des liens entre vos pages.

Nous connaissons déjà la balise a.

Pour ouvrir une autre page de notre propre site, nous pouvons écrire :

<a href="servicios.html">Voir les services</a>

Et pour revenir à l’accueil :

<a href="index.html">Accueil</a>
Lorsque vous créez plusieurs pages, vérifiez toujours que le nom écrit dans `href` correspond exactement au fichier réel. Un nom incorrect peut provoquer une erreur 404 après publication.

06

Créez des liens vers une section.

Nous pouvons aussi naviguer à l’intérieur de la même page.

Nous ajoutons d’abord un identifiant :

<section id="servicios">
  <h2>Services</h2>
</section>

Nous pouvons ensuite créer un lien vers celui-ci :

<a href="#servicios">Voir les services</a>

En cliquant sur le lien, le navigateur amènera le visiteur à cette section.

07

Liens vers d’autres sites.

Nous pouvons aussi créer un lien vers une page externe :

<a href="https://ejemplo.com">
  Consulter la page
</a>

Si vous devez l’ouvrir dans un autre onglet :

<a
  href="https://ejemplo.com"
  target="_blank"
  rel="noopener noreferrer"
>
  Consulter la page
</a>

Tous les liens externes ne doivent pas ouvrir un nouvel onglet. Utilisez cette option lorsque cela convient à l’expérience du visiteur.

08

Un bouton peut être un lien.

Sur de nombreuses pages, des éléments ressemblent visuellement à des boutons, mais sont en réalité des liens.

<a href="contacto.html" class="button">
  Présentez-moi votre projet
</a>

CSS contrôle leur apparence :

.button {
  display: inline-block;
  padding: 14px 24px;
  background: #222222;
  color: #ffffff;
  text-decoration: none;
}
Si l’élément mène à une autre page ou un autre emplacement, nous utilisons généralement un lien. L’élément button sert aux actions, comme envoyer un formulaire ou activer une fonction.

09

Ajoutez des états hover et focus.

Il est utile d’indiquer visuellement qu’un élément peut être utilisé.

.button:hover {
  opacity: 0.8;
}

Nous devons aussi prendre en compte la navigation au clavier :

.button:focus-visible {
  outline: 2px solid currentColor;
  outline-offset: 4px;
}

L’état focus-visible permet d’indiquer quel élément interactif est sélectionné lors de la navigation au clavier.

10

Utilisez des textes de lien clairs.

Le texte d’un lien doit aider à comprendre ce qui se passera après le clic.

MOINS CLAIR

Cliquez ici

N’explique pas à lui seul la destination du lien.

PLUS CLAIR

Voir les services

Indique directement ce que le visiteur trouvera.

11

Créez une section visuelle complète.

Nous pouvons associer une image, du contenu et un appel à l’action :

<section class="project">

  <img
    src="images/proyecto-web.jpg"
    alt="Vue d’un projet de création web"
  >

  <h2>Projet à la une</h2>

  <p>
    Une page simple, claire et responsive.
  </p>

  <a href="#" class="button">
    Voir le projet
  </a>

</section>

Cette combinaison revient régulièrement sur les pages professionnelles : un visuel, du contexte et une action claire.

12

Optimisez vos images avant de les ajouter.

Une image peut être parfaitement affichée et malgré tout ralentir une page si son fichier est inutilement lourd.

01

Utilisez des dimensions adaptées à l’usage réel.

02

Compressez les images avant de les publier.

03

Utilisez des formats modernes lorsque c’est pertinent.

04

Donnez des noms descriptifs aux fichiers.

Par exemple, il vaut mieux :

proyecto-diseno-web.jpg

que :

IMG_847293.jpg

RÉSUMÉ

Ce que vous avez appris.

  • Les images sont ajoutées avec la balise img.
  • src indique l’emplacement du fichier.
  • alt fournit une alternative textuelle lorsque cela est nécessaire.
  • Les images doivent s’adapter aux différents écrans.
  • Les liens internes relient les pages d’un même site.
  • Les identifiants permettent de créer des liens vers les sections.
  • Nous pouvons aussi créer des liens externes.
  • Un lien peut être présenté visuellement comme un bouton.
  • Les boutons et les liens ont des fonctions différentes.
  • Les états hover et focus améliorent l’interaction.
  • Le texte des liens doit être descriptif.
  • Les images doivent être optimisées avant la publication.

MISE EN PRATIQUE

Complétez le contenu de votre site.

Ouvrez le projet construit dans les leçons précédentes.

  1. Créez un dossier nommé images.
  2. Ajoutez au moins une image.
  3. Écrivez un alt adapté.
  4. Vérifiez que l’image est responsive.
  5. Ajoutez un lien vers une section de votre page.
  6. Ajoutez un lien vers une autre page HTML.
  7. Transformez un appel à l’action en bouton visuel.
  8. Ajoutez un état hover.
  9. Vérifiez la navigation au clavier.
  10. Vérifiez que tous les chemins fonctionnent.
Testez tous vos liens avant de continuer. Un site peut être très beau, mais un lien cassé nuit immédiatement à l’expérience du visiteur.
