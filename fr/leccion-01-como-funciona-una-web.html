LEÇON 01 · LES BASES

Comment fonctionne une page web.

Avant d’apprendre HTML ou CSS, vous devez comprendre ce qui se passe réellement lorsque vous saisissez une adresse dans le navigateur et qu’une page apparaît sur votre écran.

Niveau · Débutant Durée · 10–15 min Parcours · Création web

01

Qu’est-ce qu’une page web ?

Une page web est un document numérique qu’un navigateur peut interpréter et afficher sur un écran.

Elle peut contenir du texte, des images, des boutons, des formulaires, des vidéos, des liens et bien d’autres éléments.

Lorsque vous consultez un site, votre ordinateur ne reçoit pas une « image » de la page. Il reçoit différents fichiers et instructions que le navigateur utilise pour construire ce que vous voyez.

02

Les trois éléments à connaître.

01

HTML

Définit la structure et le contenu de la page : titres, textes, images, boutons et sections.

02

CSS

Contrôle l’apparence : couleurs, tailles, espaces, polices et disposition.

03

JavaScript

Permet d’ajouter des comportements et des interactions, comme des menus, des animations ou des actions dynamiques.

03

Que se passe-t-il lorsque vous consultez un site ?

Imaginez que vous saisissez dans votre navigateur :

digitalukhti.com

Pour simplifier, voici ce qui se passe :

01

Vous saisissez le domaine dans le navigateur.

02

Le navigateur recherche où le site est hébergé.

03

Le serveur envoie les fichiers nécessaires.

04

Le navigateur interprète HTML, CSS et JavaScript.

05

La page apparaît sur votre écran.

04

Le domaine et l’hébergement sont deux choses différentes.

Ces deux concepts sont souvent confondus lors de la création d’un premier site web.

DOMAINE

L’adresse.

C’est le nom que l’on saisit pour trouver votre site, par exemple digitalukhti.com.

HÉBERGEMENT

L’endroit où se trouve le site.

C’est le service où sont stockés les fichiers qui composent votre page.

Une façon simple de le retenir : le domaine est l’adresse d’une maison et l’hébergement est le terrain sur lequel elle est construite.

05

Quel est le rôle du navigateur ?

Chrome, Safari, Firefox et Edge sont des navigateurs.

Leur rôle consiste à lire les fichiers d’une page et à les convertir en une interface que vous pouvez utiliser.

Ainsi, lorsque nous écrirons HTML et CSS, nous donnerons des instructions au navigateur.

RÉSUMÉ

Ce qu’il faut retenir.

  • Un site est composé de fichiers.
  • HTML crée la structure.
  • CSS contrôle l’apparence.
  • JavaScript ajoute de l’interactivité.
  • Le domaine est l’adresse du site.
  • L’hébergement stocke les fichiers.
  • Le navigateur interprète ces fichiers et affiche la page.

MISE EN PRATIQUE

Regardez un site autrement.

Ouvrez un site que vous utilisez régulièrement et essayez d’identifier :

  1. Le domaine.
  2. Le menu de navigation.
  3. Les titres principaux.
  4. Les boutons.
  5. Les différentes sections.

Vous n’avez pas encore besoin de savoir comment ils sont construits. L’objectif est de commencer à reconnaître les éléments qui composent une page web.
