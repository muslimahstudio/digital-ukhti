LEÇON 09 · SITE MULTIPAGE

Créez plusieurs pages et reliez-les.

Jusqu’ici, vous avez surtout travaillé avec une seule page. Dans cette leçon, vous apprendrez à transformer votre projet en un site composé de plusieurs pages reliées entre elles.

Niveau · Débutant Durée · 30–35 min Parcours · Création web

01

Un site peut avoir de nombreuses pages.

Une page simple peut fonctionner avec un seul fichier HTML, mais de nombreux projets doivent répartir le contenu.

Par exemple, un site professionnel pourrait avoir :

index.html
sobre.html
servicios.html
contacto.html

Chaque fichier représente une page différente au sein du même site.

02

Organisez votre projet.

Votre dossier pourrait se présenter ainsi :

mi-primera-web/
├── index.html
├── sobre.html
├── servicios.html
├── contacto.html
├── styles.css
└── images/
    └── proyecto.jpg

Tous les fichiers HTML peuvent utiliser le même styles.css.

Une structure organisée évite de nombreuses erreurs lorsque le projet se développe.

03

Créez la page À propos.

Créez un nouveau fichier nommé :

sobre.html

Vous pouvez commencer par une structure comme celle-ci :

<!DOCTYPE html>
<html lang="fr">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>À propos | Mon projet</title>
  <link rel="stylesheet" href="styles.css">
</head>

<body>

  <h1>À propos du projet</h1>

  <p>
    Vous pouvez présenter votre projet ici.
  </p>

</body>

</html>

04

Reliez l’Accueil à la page À propos.

Depuis `index.html`, nous pouvons créer :

<a href="sobre.html">À propos</a>

En cliquant sur le lien, le navigateur recherchera `sobre.html` dans le même dossier.

Pour revenir à l’Accueil depuis `sobre.html` :

<a href="index.html">Accueil</a>

05

Réutilisez le même menu.

Chaque page doit permettre au visiteur de parcourir le site sans rester bloqué.

Nous pouvons réutiliser ce menu :

<nav>
  <a href="index.html">Accueil</a>
  <a href="sobre.html">À propos</a>
  <a href="servicios.html">Services</a>
  <a href="contacto.html">Contact</a>
</nav>
Lorsque vous modifiez manuellement le menu d’un site statique, pensez à le mettre à jour sur toutes les pages où il apparaît.

06

Qu’est-ce qu’un chemin relatif ?

Un chemin indique où se trouve un fichier.

Lorsque vous écrivez :

href="servicios.html"

vous utilisez un chemin relatif.

Cela signifie : cherchez `servicios.html` en prenant comme référence l’emplacement du document actuel.

07

Que se passe-t-il avec les sous-dossiers ?

Imaginez cette structure :

mi-primera-web/
├── index.html
├── styles.css
└── paginas/
    └── servicios.html

Depuis `index.html`, nous utiliserions ceci pour ouvrir Services :

<a href="paginas/servicios.html">Services</a>

Mais depuis `servicios.html`, nous devons remonter d’un niveau pour revenir à l’Accueil :

<a href="../index.html">Accueil</a>

Les deux points :

../

signifient remonter au dossier précédent.

08

Pourquoi une erreur 404 apparaît-elle ?

Une erreur 404 signifie que le navigateur ou le serveur n’a pas trouvé la ressource demandée.

Cela peut avoir plusieurs causes :

01

Le fichier n’existe pas.

02

Le nom est mal écrit.

03

Le chemin pointe vers le mauvais dossier.

04

Les majuscules et les minuscules ne correspondent pas.

09

Les noms de fichiers doivent être cohérents.

Il est recommandé d’utiliser des noms simples et descriptifs.

Par exemple :

diseno-web.html
sobre-nosotros.html
contacto.html

Évitez les espaces :

Mi Pagina Servicios.html

Une meilleure solution serait :

servicios.html

10

Conservez l’identité visuelle entre les pages.

Même si chaque page a un contenu différent, le site doit constituer une expérience cohérente.

01

Utilisez la même navigation.

02

Conservez les mêmes polices.

03

Reprenez la palette de couleurs.

04

Gardez des styles de boutons cohérents.

05

Utilisez des espacements et des largeurs similaires.

En partageant `styles.css`, il est plus facile de conserver cette cohérence.

11

Créez une structure multipage simple.

Pour vous entraîner, créez quatre pages :

index.html
sobre.html
servicios.html
contacto.html

Dans chacune, ajoutez :

<link rel="stylesheet" href="styles.css">

et le même menu de navigation.

Vous aurez ainsi un véritable petit site web et non une simple page isolée.

12

Vérifiez tous les liens.

Avant de publier, parcourez votre site comme si vous étiez un visiteur.

01

Accueil → À propos.

02

À propos → Services.

03

Services → Contact.

04

Contact → Accueil.

Vérifiez aussi les boutons, les images et les liens internes.

La navigation doit être vérifiée après chaque modification importante de la structure des fichiers.

RÉSUMÉ

Ce que vous avez appris.

  • Un site peut être composé de plusieurs fichiers HTML.
  • index.html représente généralement la page principale.
  • Les liens permettent de relier différentes pages.
  • Les chemins relatifs dépendent de l’emplacement du fichier.
  • ../ permet de remonter d’un niveau de dossier.
  • Un chemin incorrect peut provoquer une erreur 404.
  • Les noms de fichiers doivent être clairs et cohérents.
  • Plusieurs pages peuvent partager le même styles.css.
  • La navigation doit rester cohérente.
  • Tous les liens doivent être testés avant publication.

MISE EN PRATIQUE

Transformez votre projet en site multipage.

Utilisez le projet construit durant ce parcours.

  1. Conservez `index.html` comme page d’Accueil.
  2. Créez `sobre.html`.
  3. Créez `servicios.html`.
  4. Créez `contacto.html`.
  5. Reliez `styles.css` aux quatre pages.
  6. Ajoutez le même menu partout.
  7. Vérifiez tous les chemins.
  8. Consultez toutes les pages dans le navigateur.
Si une erreur 404 apparaît, ne commencez pas par modifier tout le code. Vérifiez d’abord le nom exact du fichier et le chemin écrit dans `href`.
