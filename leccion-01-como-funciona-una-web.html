LECCIÓN 01 · FUNDAMENTOS

Cómo funciona una página web.

Antes de aprender HTML o CSS, necesitas comprender qué ocurre realmente cuando escribes una dirección en el navegador y aparece una página en tu pantalla.

Nivel · Principiante Tiempo · 10–15 min Ruta · Diseño web

01

¿Qué es una página web?

Una página web es un documento digital que un navegador puede interpretar y mostrar en una pantalla.

Puede contener texto, imágenes, botones, formularios, vídeos, enlaces y muchos otros elementos.

Cuando visitas una web, tu ordenador no recibe una “imagen” de la página. Recibe diferentes archivos e instrucciones que el navegador utiliza para construir lo que ves.

02

Las tres piezas que debes conocer.

01

HTML

Define la estructura y el contenido de la página: títulos, textos, imágenes, botones y secciones.

02

CSS

Controla la apariencia: colores, tamaños, espacios, tipografías y distribución.

03

JavaScript

Permite añadir comportamiento e interacción, como menús, animaciones o acciones dinámicas.

03

¿Qué ocurre cuando visitas una web?

Imagina que escribes en tu navegador:

digitalukhti.com

De forma simplificada, ocurre lo siguiente:

01

Escribes el dominio en el navegador.

02

El navegador busca dónde está alojada esa web.

03

El servidor envía los archivos necesarios.

04

El navegador interpreta HTML, CSS y JavaScript.

05

La página aparece en tu pantalla.

04

Dominio y alojamiento no son lo mismo.

Estos dos conceptos suelen confundirse cuando alguien crea su primera página web.

DOMINIO

La dirección.

Es el nombre que una persona escribe para encontrar tu web, por ejemplo digitalukhti.com.

ALOJAMIENTO

El lugar donde vive la web.

Es el servicio donde están almacenados los archivos que forman tu página.

Una forma sencilla de recordarlo: el dominio es la dirección de una casa y el alojamiento es el terreno donde está construida.

05

¿Qué papel tiene el navegador?

Chrome, Safari, Firefox o Edge son navegadores.

Su trabajo consiste en leer los archivos de una página y convertirlos en una interfaz que puedas utilizar.

Por eso, cuando más adelante escribamos HTML y CSS, estaremos dando instrucciones al navegador.

RESUMEN

Lo que debes recordar.

  • Una web está formada por archivos.
  • HTML crea la estructura.
  • CSS controla la apariencia.
  • JavaScript añade interacción.
  • El dominio es la dirección de la web.
  • El alojamiento guarda los archivos.
  • El navegador interpreta esos archivos y muestra la página.

PONLO EN PRÁCTICA

Observa una web con otros ojos.

Abre una página web que utilices habitualmente e intenta identificar:

  1. El dominio.
  2. El menú de navegación.
  3. Los títulos principales.
  4. Los botones.
  5. Las diferentes secciones.

No necesitas saber todavía cómo están construidos. El objetivo es empezar a reconocer las piezas que forman una página web.
